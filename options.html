Prime Video Subtitle Translator

Settings & self-hosting

The extension needs your own translation server to work. Follow the guide below to deploy one in a few minutes, then paste its URL here.

Set up your translation server

Translation runs through a small proxy (a Cloudflare Worker) that holds a Google Cloud Translation API key, so the key never ships inside the extension. You run your own, so translation costs stay on your account and under your control.

Step 1 — Get a Google Cloud Translation API key

  1. Create a project at console.cloud.google.com.
  2. Enable Cloud Translation API (APIs & Services → Library).
  3. APIs & Services → Credentials → Create credentials → API key.
  4. Edit the key → API restrictions → Cloud Translation API. Leave Application restrictions = None.
  5. Make sure billing is enabled on the project (the free tier still requires it).

Step 2 — Deploy the Cloudflare Worker

Get the worker code from the repository, then in the backend folder:

git clone https://github.com/NikitaMikhailov/primevideo-subtitle-translator
cd primevideo-subtitle-translator/backend

npx wrangler login
npx wrangler secret put GOOGLE_API_KEY   # paste the key (hidden, no extra spaces/newline)
npx wrangler deploy

After deploy you get a URL like https://your-worker.your-subdomain.workers.dev.

Step 3 — Connect it

Paste that URL into the Custom proxy server field above. Done.

Cost

Google Cloud Translation: first 500,000 characters/month free, then about $20 per 1M characters. Cloudflare Workers: free tier 100,000 requests/day. The extension caches translations locally, so real usage is much lower than the number of subtitle lines.

Keep costs under control

Set a budget and quota in Google Cloud (Billing → Budgets & alerts, and Cloud Translation API → Quotas) to cap spending.
